# Results index

Small result tables, logs and figures, regenerated by the scripts in `../scripts` (see `../scripts/run_all.sh`).
Large data never goes here. Dated context for every folder is in `../docs/RESEARCH_LOG.md`.

| Folder | Produced by | What it contains |
|---|---|---|
| `anatomy/` | `drift_anatomy.py --max-train 80` | Oracle ladder on LINK, 537 pairs, gaps 1–900 d. `table_ci.csv` holds cluster-bootstrap CIs. |
| `data_efficiency/` | `drift_anatomy.py --n-trials 10 20 50 100 300` | Ladder rungs as a function of labelled-trial budget (86 pairs). |
| `anatomy_nn/` | `drift_anatomy_nn.py` | LSTM ladder (79 pairs). `matched_vs_ridge.csv` compares it with ridge on the same pairs. |
| `anatomy_matched_nn/` | `drift_anatomy.py --pairs-from anatomy_nn/ladder_nn.csv` | Ridge ladder on the LSTM pairs. |
| `drift_dof/` | `drift_dof.py` | Constrained corrections: k-channel re-learning (supervised, label-free and random selection), plus rank-r remaps (not informative; see log). |
| `recal_policy/` | `recal_policy.py` | Small-budget recalibration: per-pair CV vs shrinkage chosen from history. |
| `targeted_recal/` | `targeted_recal.py` | Label-free channel triage plus few-trial refit of only the flagged channels. |
| `replication/` | `replicate_perich.py` | Ladder on DANDI 000688, monkeys C (Chewie) and M (Mihili). |
| `channel_health/` | `channel_health.py` | Per-channel 3.4-year trajectories (`channel_day.csv`) and edge/interior slopes (`channel_slopes.csv`). |
| `failure_xdata*/` | `failure_stats_xdata.py` | Electrode failure statistics. LINK: all days, and the `_cal700` time split. Human T5: `_h2`. Chewie and Mihili: `_perich`. |
| `sim_calib_split/` | `calibrate_sim.py --max-day 700` | Simulator calibration on LINK days < 700 (time split). |
| `figures/` | `make_figures.py` | Figures (PNG for viewing, PDF for the manuscript). |
| `archive/` | earlier runs | Superseded interim results (pilot, partial anatomy, the mis-regularized calibration) kept for the record. |

The `*.log` files are the console output of the corresponding runs.
